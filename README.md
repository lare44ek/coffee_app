# Приложение для учёта продукции в кофейне

## Описание

`Effoc app` — это мобильное приложение, разрабатываемое для упрощения и автоматизации учёта продукции в кофейне. Основная цель приложения — генерировать маркировки с информацией о дате вскрытия и сроке годности продукта, а также отслеживать историю этих маркировок. Это помогает персоналу кофейни эффективно управлять свежестью ингредиентов.

## Цели

*   **Упрощение маркировки:** Автоматически рассчитывать и формировать этикетки для вскрываемых продуктов с указанием даты и времени вскрытия и окончания срока годности.
*   **Отслеживание:** Хранить историю сгенерированных и, потенциально, отсканированных маркировок.
*   **Удобство использования:** Предоставить интуитивно понятный интерфейс для персонала кофейни.
*   **Производительность:** Будет работать даже на курилке

## v0.1 alpha

Пока реализованы следующие функции:

*   **Авторизация:** Простой экран логина для входа в приложение.
*   **Генератор маркировок:** Выбор продукта из предустановленного списка, расчёт даты/времени окончания срока годности и отображение готовой маркировки.
*   **Сканирование QR-кода:** Экран с доступом к камере для сканирования QR-кодов (функционал распознавания пока не реализован, но экран интегрирован).
*   **История маркировок:** Возможность сохранять сгенерированные маркировки и просматривать их список на отдельном экране.

## v0.2 sigma

Главное изменение версии — приложение перестало быть полностью офлайновым и получило собственный бэкенд. Данные теперь хранятся на сервере и синхронизируются между устройствами.

*   **Бэкенд и база данных:** Развёрнут REST API (Node.js + Express) поверх MariaDB. Каталог продуктов, остатки, заметки и история маркировок теперь подгружаются с сервера и сохраняются между сессиями.
*   **Каталог из БД:** Список продуктов больше не захардкожен — он приходит с сервера, продукты можно добавлять и редактировать.
*   **Полноценная авторизация:** Экраны регистрации и входа работают через сервер, пароли хранятся в виде bcrypt-хешей.
*   **Сохранение сессии:** После первого входа пользователь остаётся залогиненным — повторно вводить логин и пароль не нужно.
*   **Профиль:** Новая вкладка с именем пользователя и кнопкой выхода из аккаунта. Есть возможность редактирования отображаемого имени.
*   **Иконка приложения:** Добавлена иконка для iOS, Android и macOS.

## v1.0.0 — финальный релиз

Первая полноценная, готовая к ежедневному использованию версия. Главная фича релиза — работающее сканирование штрих-кодов товаров, ради которого приложение и задумывалось.

*   **Сканирование штрих-кодов (EAN-13):** Товары в каталоге получили штрих-коды. Сканер наводится на код на упаковке, находит товар в каталоге и автоматически подставляет его — на экранах «Маркировка» и «Остатки». Неизвестный код подсвечивается сообщением «код не привязан к продукту».
*   **Скан на «Остатках»:** Отсканированный товар теперь сразу попадает в остатки в раздел «Закрыто».
*   **Бэкенд под штрих-коды:** В таблицу `products` добавлено поле `barcode` (уникальное), API отдаёт и принимает его во всех операциях с каталогом, повторная привязка занятого кода возвращает понятную ошибку (409). В базу залиты реальные коды товаров кофейни.
*   **Иконка сканера:** Заменена с QR на штрих-код — сканируем именно их.
*   **Стабильный деплой:** Сервер переведён на Docker Compose, доступ по HTTPS через `api.mango-kokos.ru`.
